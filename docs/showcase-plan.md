# dsh-meta-validate 对外展示方案

日期：2026-08-16
目标：让第一次看到项目的人，30 秒内明白“这是给 Agent 运行时装的安全自进化回路”，10 分钟内被证据说服。

## 1. 一句话定位

**给 DeepSeek Harness 装上第二个验证器：agent 可以在不能热替换自己的前提下，完成“观察 → 迭代 → 核验 → 冷替换 → 回滚”的运行时自进化。**

- 《别让 agent 给自己当裁判：自进化的唯一安全路径是冷替换 + 独立验证》

推荐主标题：**《Agent 怎么安全地改自己？》**——技术人一看就懂问题有多难。

## 3. 文档结构（README / 文章共用）

1. 开场钩子：自指困境（agent 不能在自己运行的 loop 里改自己的 loop）
2. 一分钟读懂：observe → propose → validate → cold-apply → rollback
3. 为什么冷替换是唯一安全路径（对照 prime-agent 的 refine 管线）
4. 为什么验证必须独立（对照 Tycho / ARC-AGI-3 的确定性帧对齐）
5. 四个组件：observer / builder / verifier / gate（TCB）
6. 硬核证据：从零成长 L1-L5、Δsuccess +3、69/69 测试、宿主闭环 pass=true
7. 快速开始 + 验收命令
8. 路线图与已知边界（loop 层未放开是设计项，不是缺陷）
