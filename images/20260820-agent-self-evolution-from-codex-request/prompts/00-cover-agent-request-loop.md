# Article cover prompt

Use case: technical article cover
Asset type: wide editorial illustration, 16:9
Primary request: A publication-quality conceptual cover for an article explaining the real communication path of an AI coding agent. Show one luminous request stream descending through three clearly separated architectural layers: a personal computer client at the top, a protocol adapter in the middle, and an upstream model service at the bottom. A second stream returns along a clean outer arc, carrying a small tool-result signal back to the client. The image should communicate “action is a loop across boundaries”, not “the model is a magical brain”.
Scene/backdrop: deep navy technical workspace with subtle grid, restrained atmospheric depth, generous negative space around the central three-layer stack.
Subject: a transparent woven path / fiber-optic ribbon passing through three suspended glass layers; top layer has a terminal window and small file/command symbols; middle layer has a translation prism and a state ledger; bottom layer has a calm model node and routing manifold; the return ribbon carries a green verification pulse.
Style/medium: refined scientific editorial illustration, dark blue, cyan, amber and muted green palette, clean geometry, realistic glass and fiber materials, subtle glow, no cartoon characters, no clutter.
Composition/framing: wide 16:9 horizontal cover, centered vertical stack, return path isolated on the right edge, strong top-to-bottom reading order, large quiet area on the upper-left for platform title overlay if needed.
Lighting/mood: thoughtful, precise, calm engineering clarity; cyan active request, amber adapter boundary, violet model service, green verified result.
Text (verbatim): none
Constraints: no text, no letters, no numbers, no labels, no logos, no watermark; do not render pseudo-code or tiny UI text; preserve clean layer separation and readable negative space.
Avoid: chaotic arrows, tangled wires, crowded dashboards, humanoid robot, giant brain, mystical AGI imagery, excessive neon, visual noise.
