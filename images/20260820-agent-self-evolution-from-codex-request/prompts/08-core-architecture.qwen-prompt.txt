生成一张无文字的 Agent 核心架构总览背景，1536×1024 横版。它要把意图与约束、工作包与能力、执行与状态、改进控制面组织成四层，同时让读者看清信息流、能力流、进化流与信任边界。它不是模块清单；每条流必须有不同来源、方向和终点。

采用纵向四层的透明系统剖面，轻微等距俯视，深石墨背景上有暖灰玻璃层板。最上层是意图与约束：用户目标纸片、稳定规则册、项目文件和权限印章，各自独立。第二层是工作包与能力：一个上下文装配器从上层取材料；旁边是一条青色能力总线，连接无文字的 skill 手册、工具接口和远端能力接驳。第三层是执行与状态：推理棱镜提出动作，经预检门进入工具运行台、远端服务和外部环境；结果被装入状态玻璃片与事实档案。第四层在右侧独立成一个琥珀到绿色的改进控制面：观察、假设、候选、独立验证、Gate、冷替换/回滚，形成独立环而不占据执行台。

三条流必须一眼区分：蓝色信息纤维自上向下进入工作包，蓝绿结果纤维自第三层回到状态；青色能力总线只连接第二层到第三层的执行入口；琥珀到绿色进化流只从第三层的事实档案进入第四层，只有 Gate 的单一绿色细线在回合边界回到第二层能力模块。第三、四层之间横贯一条连续的深灰信任膜，带锁芯和校准尺无文字图标；候选绝不能穿过膜或直接改写执行 runtime。所有四层、三条流、信任膜与 Gate 交点均预留中文标签区。绝对不要任何文字、字母、数字、品牌、UI、机器人、城市或普通箭头盒图。
