生成一张无文字技术关系图背景，1536×1024 横版，解释“context 是本轮工作台，memory 是可选择、可检索、可回源的材料库”。画面必须按上→下→回注入的顺序可读：上层透明工作台只放本轮可见材料；下层档案库保存不同时间尺度的信息；两层之间有筛选和预算闸门；未经验证的猜测不能直接入库。

深石墨与暖灰纸张背景，精密图书馆和实验工作台的剖面隐喻，克制的科学插图风格，无任何文字、字母、数字、logo、UI 或卡通角色。上方居中是一块浅蓝透明玻璃工作台，留出四块干净标签区；台面上只出现无文字的任务便签、规则页、最近工具结果玻璃片和当前光标，亮度最高。下方是一座分层档案库：左侧会话历史卷轴，中间项目文件和规则册，右侧用户偏好抽屉与实验记录盒；各层有可见材质差异但无文字。工作台与档案库之间只允许三条细路径：一条青色检索纤维从档案库上行，先穿过带孔筛网和一个小型预算刻度门；一条琥珀色长历史进入压缩器后变成较薄摘要片，但摘要片始终用细线回连原始档案；一条暗红虚线猜测片在档案库入口被挡住并落到旁侧暂存托盘。

不要把档案库直接倒进工作台，不要把记忆画成大脑。所有通路不交叉，工作台、检索闸门、档案库、暂存托盘周围留出至少 180×54 像素的平坦区域，供后期放置中文标签。色彩语义：蓝色为本轮可见，青色为检索注入，琥珀为压缩，绿色为已验证档案，暗红为未验证猜测。
