生成一张无文字技术关系图背景，1536×1024 横版，解释 skill、tool、MCP 的位置关系：skill 是方法说明，tool 是受参数与权限约束的动作接口，MCP 是把外部 tools/resources/prompts 接入目录的协议总线。画面必须让读者看到三者不是并列同义词，更不能让 skill 直接执行。

采用三层舞台与透明电缆的剖面，深蓝暖灰背景，手工精密仪器与科学图解结合的风格。顶层悬浮一本打开的操作手册，页签、步骤折页和铅笔标记均无文字；它向中层发出一条细的虚线光纤，表示指导而非执行。中层是四个带明确机械孔位与保护罩的接口模块，模块之间保持间隔，表现 tool schema/权限边界；它们只有向下的一条实线连接。底层是横向的透明接驳总线，左侧延伸到远端外部能力群：工具柜、资源档案匣、提示模板卷轴三类无文字对象；总线向上把其中一部分能力注册到中层接口，但不直接接触顶层手册。右侧单独放一个受控执行台，只有中层接口可通过闸门进入执行台。
