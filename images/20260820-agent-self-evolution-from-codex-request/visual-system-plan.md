# Loom 文章视觉系统：总览一张，局部逐张解释

## 使用原则

- **总览图**负责建立读者的空间地图，只放角色、边界和两条循环。
- **局部图**每张只回答一个可验证的问题，采用管线/剖面图，不复述总览。
- **未来概念图**不作为架构证据；它只表达设计方向，必须配“概念示意”图注。
- 所有包含术语、步骤、数据或边界的图，由确定性 SVG/PIL 排版生成；AI 背景只提供材质和情绪，不承载文字或连线。

## 图 01：大结构总览的构图

总览不画成一堆模块。采用“**双环围绕一个稳定执行核**”的结构：

- 中央是 Agent runtime，表示它只完成眼前任务与真实工具调用。
- 内环是任务回路：请求工作包 → 模型推理 → 工具执行 → 结果回灌。
- 外环是进化回路：失败事实 → 假设 → 受限候选 → 独立 Verifier → Gate → cold install / rollback。
- 外环与中央之间只允许两处受控交点：`evidence input` 与 `approved install`。没有从候选直接改 runtime 的箭头。
- 外圈底部是一段连续、不可拆的 TCB 带，放 Verifier、Gate、回归集、权限边界；候选的箭头碰到该带只能被验证，不可进入。

总览的阅读顺序固定为左上顺时针：先看任务怎么跑，再看失败如何进入进化回路，最后看为什么验证链不能被进化对象改写。

## 图 00：未来概念图的语义

画面是一台在暗处工作的“织机”：中间是一枚稳定、克制的执行核心；外围悬浮着一圈透明检验环，环上有细小刻度、光栅和闸门。左侧红色碎片代表失败与反例，进入外环后被分拣；只有少量青绿纤维通过检验环，被编织成可拆卸的能力模块，轻轻接入核心周围。被拒绝的碎片沿另一条路径回到档案层，而非被掩盖。核心从不直接触碰检验环的锁芯。

它表达的是“成长来自可证伪的反馈，稳定来自外部边界”，不是“模型觉醒”或“自己无限变强”。

图注：`概念示意：Loom 研究的是受证据与回滚约束的 Agent 改进路径，不代表通用世界模型已经实现。`
